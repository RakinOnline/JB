# JB Launcher (Android 4.x Jelly Bean style, Nova-style settings)

Build: push this folder to a GitHub repo -> Actions tab -> "Build APK" -> download artifact `JellyBeanLauncher-apk`.
Install app-release.apk, press Home, choose "JB Launcher" -> Always.

Settings: open "JB Launcher settings" (app icon) or long-press empty home space -> Launcher settings.
Hold Volume Down for 2 seconds inside Settings to unlock the hidden Labs menu.

Custom icons: put PNGs named ic_<package_with_underscores>.png into app/src/main/res/drawable-nodpi/ and rebuild,
or long-press any icon -> Edit -> Choose icon image.
